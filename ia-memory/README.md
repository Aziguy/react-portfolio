# ia-memory

Mémoire de travail du projet : ce qui a été fait, pourquoi, et ce qui reste à faire.
Ce répertoire est versionné pour que le contexte survive aux sessions et aux contributeurs.

| Fichier | Contenu |
| --- | --- |
| `ARCHITECTURE.md` | Structure du code et conventions |
| `CHANGELOG.md` | Journal des changements par session |
| `BACKLOG.md` | Ce qui reste à faire, par priorité |
| `decisions/` | Décisions d'architecture (ADR), une par fichier |
| `sessions/` | Comptes rendus de session, datés |

## Convention

Une décision structurante donne un fichier `decisions/NNNN-titre.md`.
Une session de travail donne un fichier `sessions/AAAA-MM-JJ-sujet.md`.
