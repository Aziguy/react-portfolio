# 2026-09-05 — Enrichissement de la section Projets

## Objectif

Récupérer les nouveaux dépôts publics GitHub et les intégrer à la section Projets.

## Méthode

Comparaison de `gh api users/Aziguy/repos?sort=pushed` avec les dépôts déjà référencés dans
`src/data/projects.js`. Lecture du README et vérification que la démo répond avant d'écrire
la description — aucune formulation n'est déduite du seul nom du dépôt.
