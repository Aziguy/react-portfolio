# 2026-09-05 — Enrichissement de la section Projets

## Objectif

Récupérer les nouveaux dépôts publics GitHub et les intégrer à la section Projets.

## Méthode

Comparaison de `gh api users/Aziguy/repos?sort=pushed` avec les dépôts déjà référencés dans
`src/data/projects.js`. Lecture du README et vérification que la démo répond avant d'écrire
la description — aucune formulation n'est déduite du seul nom du dépôt.

## Dépôts retenus

| Dépôt | Pourquoi |
| --- | --- |
| `kenako` | Cinq applications sur un socle commun, design system, cartes Leaflet, démo en ligne |
| `lgi-web-site` | Site e-commerce bilingue et back-office complet, démo en ligne, passe d'accessibilité documentée |

## Dépôts écartés

- `portfolio` et `Portfolio-Website` : anciennes versions de ce portfolio, superflues.
- `aziguy` : dépôt de profil GitHub.
- `react-pwa-app` : encore au stade du gabarit Vite.
- `design-croke` : doublon de `design-croke-web`, déjà présent.

## Effets de bord traités

- `pwa-pc-config` renommé « Configurateur PC LeGuide » : le même client a maintenant deux
  réalisations dans la section, il fallait lever l'ambiguïté.
- Mise en avant ramenée à trois projets pour qu'elle garde du sens.
- Configuration Playwright durcie après un faux positif : un serveur d'un autre dépôt
  occupait le port 4173 et la suite testait la mauvaise application. Port dédié 4319 et
  `reuseExistingServer: false`.

## Vérifications

`npm run verify` puis `npx playwright test` : 52 tests unitaires et 28 end-to-end au vert.
